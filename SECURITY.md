# Security Policy

## Reporting a vulnerability

Please report security issues through GitHub's private vulnerability reporting flow instead of opening a public Issue. Include the affected Skill, the smallest safe reproduction, and the potential impact. Do not include real account data, credentials, cookies, tokens, signed URLs, or chat content.

## Data boundary

This repository must contain only Skill instructions, reusable code, schemas, and synthetic fixtures. Runtime archives, browser sessions, API responses, attachments, reports, and logs belong outside the repository.

## Supported releases

The latest commit on `main` is the supported public snapshot. Older tags are retained for reproducibility but may not receive fixes.
